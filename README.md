# bike--buyer-analysis-excel
Welcome to the **Bike Buyers Analysis Dashboard** project! This repository contains the documentation and dataset breakdown for an interactive Excel dashboard built to analyze customer purchasing behavior, demographics, and lifestyle factors influencing bike purchases.

## 📊 Project Overview
This project examines customer demographic and behavioral data to uncover key insights into who buys bikes. Built entirely in Microsoft Excel, the dashboard aggregates raw customer records into dynamic pivot tables and charts, allowing stakeholders to filter and explore data based on geographic regions and customer gender.

## 🔍 Key Dashboard Features & Visuals

The Excel dashboard includes the following metrics and visual components:

* **Total Customers vs. Bike Purchasers:** High-level summary cards tracking total records and conversion rates.
* **Purchased Bikes by Occupation:** Bar charts showing which professions (e.g., Professional, Manual, Management) drive the highest bike sales.
* **Car Ownership Distribution:** Analysis of whether owning a car correlates with purchasing a bike.
* **Commute Distance Analysis:** Insights into how travel distance to work impacts the decision to buy a bike (e.g., 0-1 miles vs. 5-10 miles).
* **Educational Background (Degrees):** Breakdown of customer purchasing trends by education level (e.g., Bachelor's, Graduate Degree, High School).
* **Gender Breakdown:** Comparative metrics displaying purchasing preferences between male and female demographics.

## 🎛️ Interactive Slicers

To make the dashboard fully dynamic and interactive, the following Excel slicers are connected to all pivot charts and tables:

1. **Region Slicer:** Instantly filters the entire dashboard by geographic market (e.g., Europe, North America, Pacific).
2. **Gender Slicer:** Allows quick toggling between All, Male, and Female customer segments to isolate demographic-specific insights.

## 🛠️ Built With

* **Microsoft Excel:**
* **Data Cleaning & Preparation:** Power Query (or formulas) used to handle missing values, clean text formatting, and categorize age brackets/commute distances.
* **Analysis:** Pivot Tables for data aggregation.
* **Visualization:** Excel Pivot Charts, conditional formatting, and customized layout design.
* **Interactivity:** Form Controls / Slicers connected across multiple pivot tables.

## 🚀 How to Use the Excel File

1. Download the `.xlsx` file from the repository.
2. Open the file in Microsoft Excel (Excel 2016 or newer recommended to fully support slicer functionality).
3. Navigate to the **Dashboard** worksheet.
4. Click on any button in the **Region** or **Gender** slicers to dynamically update the charts and metrics in real time.
5. (Optional) Inspect the **Data** or **Pivot Summary** tabs to review the raw dataset and backend calculations.
